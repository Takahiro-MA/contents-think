指定された章番号に基づいて、1章分を執筆します。

**引数:** $ARGUMENTS（章番号。例: `3` → 第3章を執筆）

## 実行手順

1. **仕様読み込み**
   - 現在のプロジェクトの `thinking-hub.md` から該当章の仕様を読む
   - `CLI/workspace/shared-characters.md` でキャラクター設定を確認

2. **スタイル参照**
   - `../kindle2/` 配下の既刊書籍（Git本・TDD本等）の同等の章を読み、文体・構成・トーンを把握
   - 特に章の冒頭引用、シーン区切り、技術解説ボックス、コラム、振り返り、やってみよう、次回予告のフォーマットを踏襲

3. **執筆**
   - thinking-hub.md の各シーン仕様に忠実に執筆
   - 文体は「ですます調」で統一
   - キャラクターの口癖を自然に配置
   - 技術コマンド・設定例は公式ドキュメントと照合してから記載
   - 前章の次回予告と冒頭が繋がるようにする

4. **出力**
   - `../kindle2/<書籍ディレクトリ>/epub/` に所定のファイル名で出力
   - ファイル名は既存ファイルの命名規則に従う

## 注意事項
- 1章あたりの目安は6,500〜9,000字（地の文）
- 技術解説ボックスは1章に1〜2つ、コラムは1つ程度
- 「やってみよう」は読者が実際に手元で試せる具体的な内容にする
