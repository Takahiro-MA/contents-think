description: アプリ要件検討プロジェクトを開始
---

以下のファイルを読み込んでください：
- CLI/workspace/[ユーザーが指定したプロジェクト名]/project_rules.md
- CLI/workspace/[ユーザーが指定したプロジェクト名]/thinking-hub.md

その後、`project_rules.md` の BOOT BLOCK に従い、セッションを開始してください。

デフォルトモードは **Sparring Mode** です。
ユーザーに今日のテーマを確認してから、議論を開始してください。

※ `project_rules.md` が無いプロジェクト（A系統の通常書籍）は、`thinking-hub.md` とリポジトリルートの `CLAUDE.md` のみ読み込んで開始する。
