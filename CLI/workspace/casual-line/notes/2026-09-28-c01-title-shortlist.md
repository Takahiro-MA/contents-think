## 1. 必須条件ふるい

条件: ①メインタイトルだけで「AIの入門・始め方の本」と分かる ②中身と一致 ③誇大・根拠のない約束なし、サービス名・価格なし。

### 落とした案（理由1行）

| 案 | 理由 |
|---|---|
| AIを一度も使ったことがない人だけ読んでください | ②「だけ」が、一、二度でやめた人（本書の対象の半分）を締め出す |
| AIに乗り遅れたと思っている人へ | ①入門書か評論か読めない |
| まだAIを使っていないあなたへ | ①手紙調で、始め方の本だと伝わらない |
| 最初の10分でAIが使えるようになる本 | ③「10分で使えるようになる」は本全体の約束として強すぎる（10分は第4章の話） |
| 3つの約束だけで始めるAI | ②3つの約束は安全ルール（第8章）で、始め方の手段ではない |

## 4. 上位4案

### 1. AIって、どうやって始めるの？
- サブタイトル: **まだ使っていない人・やめてしまった人のための生成AI入門 ―― スマホで最初の10分**
- 長所: 読者が口に出せなかった疑問そのままで、恥ずかしさを代わりに言う。本書はこの問いに第3・4章で正面から答えるので約束と中身が一致する。書名の重複は実測でゼロ
- 弱点: 「どうやって始める」は検索サジェストに出ていないので、検索はサブタイトルの「生成AI入門」頼み。疑問形は類書と並ぶと軽く見える可能性

### 2. そろそろAI、始めませんか？
- サブタイトル: **生成AI 初心者のためのやさしい入門 ―― 難しい言葉なし、最初の10分と3つの約束**
- 長所: 急かさない誘い方で、第1章「あなたは遅れていない」のトーンと合う。重複ゼロ。ストレート路線を守りつつ定番感がない
- 弱点: メインに「入門」「初心者」がなく、検索はサブタイトル任せ。呼びかけ型は表紙でのインパクトがやや弱い

### 3. AI初心者は、まずここから。
- サブタイトル: **まだ使っていない人のための生成AI入門 ―― スマホで最初の10分と、守れば安心な3つの約束**
- 長所: メインに実サジェスト語「AI初心者」が入り、4案で検索に一番強い。「最初の1冊」という位置づけが一目で分かる
- 弱点: 近似書名（『生成AI入門 まず何を使えばいい？』）があり、文言も平凡で指を止める力は4案で最弱

### 4. 今さらだけど、AIを始めたい（著者の既存候補B）
- サブタイトル: **生成AI 初心者がスマホで最初の10分を越えるための入門**
- 長所: 読者の内心の恥をタイトルが先に口にする（著者評価済み）。「今さら聞けない〜」系が抱える同名問題はない
- 弱点: 『今さらAIはじめたい超初心者ですが、…』（2025/10/3）とかなり近く、並ぶと見分けにくい。「今さら」は既刊のAI入門で使われすぎている

### 参考（上位外）: メッセージが送れれば、AIは使える
採点は12点で同点首位、重複もゼロ。ただし著者が2026-09-24に「ひねり過剰」として棄却したLINE案と同型の「常識書き換え型」なので上位には入れない。ストレート路線を見直すときだけの再検討候補。

## サブタイトルの共通方針
- 検索語は「生成AI」「初心者」「入門」を入れる。「生成AI超入門」は既刊に多いので使わない
- 「一度も使ったことがない人へ」は三浦直人の既刊サブタイトルと重なるので「まだ使っていない人」に言い換える
- 「いちばんやさしい」は③（根拠のない最上級）に当たるので使わない（既存候補Cにも該当）
