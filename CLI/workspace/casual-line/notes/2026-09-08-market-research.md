# カジュアル本ライン（99円〜低価格帯）市場実態調査

> 位置づけ: 旗艦技術書シリーズとは別に「軽い工数×低価格×別ペンネーム」のカジュアル本
> ラインを立ち上げる構想（2026-09-07発案）の、Phase 0相当の実態調査。
> 3並列調査（KDP経済・KU市場の型・法規制）の統合レポート。追記のみ。

## 1. 経済の実態（公式ソースベース・確度高）

### ロイヤリティ
| 価格 | 方式 | 手取り/部 | 備考 |
|---|---|---|---|
| 99円 | 35% | **約31.5円** | 配信コストなし。セレクト不要 |
| 250円 | 70% | **約156〜158円** | **KDPセレクト登録（90日電子版独占・自動更新）が必須**（日本の70%要件） |

- 手取り単価は250円が99円の**約5倍**。
- 配信コストは日本¥1/MB（10MB以上は免除という逆転規定あり）。

### KENP（KU既読ページ収益）
- **購入とKENPは完全に別立て。売れた本はKENPにならない**（KENPはKU会員が借りて読んだページのみ）。
- 円建て単価はAmazon非公表。著者逆算の実勢値: 2024年 約0.42円 → 2025年末 約0.30円 → 2026年1月 約0.37円/ページ。**下落トレンドかつ不安定**。
- 短い本の1読了収益目安: 100ページ≒30〜42円、150ページ≒45〜63円。
- 価格はKU会員の収益に影響しない（借りて読むため）。価格が効くのは非KU購入層のみ。

### AI生成コンテンツのKDPポリシー（重要）
- **AI-generated**（AIがテキストを作成。人間が大幅編集しても分類不変）＝**申告義務あり**。
- **AI-assisted**（人間が作成した内容のAIによる編集・校正・壁打ち）＝申告不要。
- 「Claudeと協業で小工数」のワークフローは**AI-generated申告が必要になる可能性が高い**。
  申告はAmazonへの内部開示で、現時点で読者向け表示はされない。未申告はアカウント措置リスク。
- 出版数上限: フォーマットごと週10タイトルまで（2025年後半改定）。
- 表紙を生成AIで作る場合、その部分もAI-generated申告対象。

### ペンネーム
- **同一KDPアカウント内で書籍ごとに著者名を変えるのは公式に可能**。著者ページ・レビューも分離。
- アカウントの複数保有は規約違反（1人1アカウント原則）。**分けるのは著者名であってアカウントではない**。
- Author Central登録上限は3〜7件との非公式報告（未検証。増やす前にKDPサポートへ要確認）。

## 2. KUカジュアル本市場の「型」（二次情報ベース・参考値）

- **実在の成功モデル: 「なにおれ」ミニマリスト式シリーズ**
  84〜177ページ／250〜350円／全冊KU／「ミニマリスト式超○○術」の統一タイトル型で10冊完結
  → 目指すラインの生きた見本。
- 文字数と価格の定石: 2〜3万字→250〜350円、4〜5万字→500〜700円。
  **99円は期間限定ブースト用で、定価運用は主流でない**。
- 売れやすいジャンル: ビジネス自己啓発／副業投資／健康美容／趣味実用（マイクロニッチ）／学習資格。
  売れにくい: 小説・エッセイ・写真集・時事。
- 広いジャンル名（釣り・キャンプ等）は既刊数百件で飽和。勝ち筋は
  **「ジャンル×切り口×体験」のマイクロニッチ化**（例:「ミニマリスト式」のような独自フレーム）。
- 訴求点は実質タイトルと表紙のみ（読者の判断は3秒）。表紙はCanvaテンプレ運用が標準。
- **AI量産本への逆風は強い**（2026Q1新刊の40%超がAI関与、検索除外を求める読者ニーズあり、
  Amazonはアカウント単位の執行を強化）。低評価の典型は「AI特有の似た構成の反復」「水増しで中身が薄い」。
  → **差別化の核は実体験の具体エピソード**。
- 収益事例（24冊で月5〜7万円等）は伝聞ベース。**定量ゲートには使わず参考値扱い**。

## 3. 法規制の線引き（一般的整理・個別判断は要専門家確認）

- 規制の主対象は**広告・表示**であり書籍本文そのものではない。ただし
  **タイトル・商品説明文・キャッチコピーは「表示」として規制対象になり得る**。
- 「必ず痩せる」「誰でも稼げる」等の断定・保証タイトルが最もリスク高（景表法の優良/有利誤認）。
- 免責文言は免罪符にならない（消費者庁が打消し表示の効力を否定）。
  安全性を担保するのは**表現の抑制**: 特定商品名を出さない／断定しない／体験は一人称に留める。
- KDP側も健康誤情報にゼロトレランス（アルゴリズム自動削除あり）。

### ジャンル別リスクマトリクス
| ジャンル | リスク |
|---|---|
| 趣味入門（料理・園芸・DIY・カメラ・釣り等） | **低** |
| 生活改善（睡眠・片付け・時短・習慣化） | 低〜要注意（タイトル表現次第） |
| ダイエット・美容の体験談 | 要注意（商品名明示・数値保証はNG） |
| 特定疾患の改善・闘病＋療法推奨 | 要注意〜避ける |
| 代替療法の医療代替推奨 | 避ける |
| 副業・投資「誰でも稼げる」系 | 要注意〜避ける（景表法＋金商法、個別銘柄推奨は無登録投資助言リスク） |

## 4. 統合結論 → カジュアルライン設計への示唆

1. **価格: 定価250円＋KDPセレクトを基本形に**。99円定価は手取り1/5でKENPも増えない
   （KU会員は価格無関係に読む）ため、合理性が薄い。99円は発売時ブーストの一時施策に限定。
2. **収益設計: 1冊あたり期待値は小さい**（購入157円/部、KU読了30〜60円）。
   成立条件は「なにおれ」型＝統一フォーマットのシリーズ多冊展開×低工数。
   KENPレートは下落傾向なのでKU一本足は避け、購入＋KUの両輪で。
3. **ジャンル: 趣味入門系マイクロニッチが規制・市場の両面で最有力**。
   著者の実趣味から選び、実体験エピソードを必ず入れる（AI量産本との差別化の核＝品質フロア）。
   健康系は生活改善（習慣・片付け・時短）の範囲に限定し、医療・効能に踏み込まない。
4. **ブランド: 別ペンネーム（同一アカウント内）で防火壁**。旗艦シリーズと完全分離。
5. **コンプライアンス運用**: タイトル・商品説明文のチェックを出版ゲートに（本文より表示が本丸）。
   AI関与の申告方針を最初に決めておく（このラインはAI-generated申告前提が安全側）。
6. **プロセス: lite版ワークフローを別途明文化**（重厚hub→5行設計、3視点→1周レビュー等。
   コンプラチェックと事実照合は格に関係なく維持）。
