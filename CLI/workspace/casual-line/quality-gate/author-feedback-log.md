# 第3層: 著者レビューの答え合わせ台帳

> 目的: 第1層（`gate.py`）と第2層（`rubric.md`）を通した本に、著者がどれだけ・どんな指摘をしたかを記録し、ゲートの見落としを見つける。
> 指摘の正典は各本の `review-notes.md`。ここは件数と分類、ゲートで拾えたかどうかだけを書く（指摘の中身を転記しない）。
> 更新: 著者レビューが一区切りついたら（「反映して」の単位で）その本の行を更新する。見落としが出たときの手順は `README.md`「ゲートの更新手順」。

## 分類の定義

| 種類 | 含むもの |
|---|---|
| 事実・安全 | 事実の誤り・古い情報、体験の作り話・未確認の体験、約束（「そのまま書きます」等）の不履行、安全・機密の注意の不足 |
| 文体 | 専門用語、分かりにくい抽象語、主語のぶれ、削った跡の継ぎ目 |
| AIっぽさ | 決め台詞、慰め・許可の言葉、「AではなくB」、同じ型の反復 |
| 構成・満足感 | 章・節の過不足、対象読者の明記、具体例の不足、読後の満足 |
| 表現・コンプラ | 表現の強さ（怖がらせすぎ・誇大）、景品表示法・商標・KDP規約に関わる表現 |
| 見た目 | 組版（改行・行間・箇条書き）、画像・画面キャプチャ |
