# レビュー2: 技術専門家視点（Linux/CLI正確性）

## A（必須修正）

### A-1: grep -cコマンドの修正
ペルソナAの「具体的な悩み」欄に記載されたコマンド例が不正確。`grep -c 'ERROR' ... | sort | uniq -c`という記述は誤り。`grep -c`は件数（整数）を返すため、その後にパイプで`sort | uniq -c`を繋げても意味をなさない。正しくは`grep 'ERROR' ... | awk '{print $4}' | sort | uniq -c | sort -rn`に修正する。

### A-2: パーミッションのファイル/ディレクトリ別の意味の違いを明記
パーミッション（rwx）の説明において、同じビット表記でもファイルとディレクトリとで意味が異なる点を追記する。ファイルのxは「実行可能」、ディレクトリのxは「中に入れる（cd可能）」という違いは初学者が特に混乱する箇所であり、技術解説ボックスまたはシーン分解に明示する。

### A-3: SIGINTの追加
killコマンド・シグナルの説明にSIGINT（シグナル番号2、Ctrl+C）を追加する。読者が日常的に使っているCtrl+Cが実はシグナルの一種であるという「気づき」は、シグナルの概念を身近に感じさせる重要な接続点となる。

### A-4: 「非ログイン対話シェル」の正確な用語
ドットファイルの章（.bashrcが読み込まれるシェルの説明）で「対話シェル」と記載している箇所を「非ログイン対話シェル」に修正する。「ログインシェル」（.bash_profileが読まれる）と「非ログイン対話シェル」（.bashrcが読まれる）の区別は正確な用語で記載する必要がある。

## B（推奨修正）

### B-1: locateコマンドの注記
findコマンドの説明箇所に、`locate`コマンドについての注記を追加する。`locate`は別途パッケージ（`mlocate`または`plocate`）のインストールが必要なため、本書ではfindを中心に扱う旨を明示する。

### B-2: Useless Use of Catの注記
パイプのストーリーラインで`cat file | awk '...'`パターンを使う箇所に補足を追加する。本来`awk '...' file`と書けるが、初学者向けにデータの流れを視覚的に理解させるためにcat付きの書き方を採用している旨を注記する（本番コードでは省略が推奨される旨も添える）。

### B-3: ls | grep → findへの修正
実践ワークでlsをパイプで繋ぐ使用例をfindに変更する。`ls | grep`はファイル名にスペースが含まれる場合に誤動作するため、より堅牢な`find`を使う形に修正する。

### B-4: シバンのポータビリティ注記
シェルスクリプトの章でシバン（`#!/bin/bash`）を扱う箇所に、`#!/usr/bin/env bash`のほうがポータブルである旨を補足する。環境によってbashのパスが異なるケースへの対応として言及する。

### B-5: macOS zsh対応の追記
ドットファイルの章でmacOS環境向けに`.zshrc`／`.zprofile`への対応を追記する。macOSはCatalina以降デフォルトシェルがzshのため、読者層（ペルソナB・C含む）に配慮した注記が必要。

### B-6: sed/awkのBSD/GNU差異の補足
AI・ChatGPT反論への回答（反論4相当の箇所）で、sed・awkの拡張機能にはOS間（BSD系/GNU系）で差異がある旨を補足する。macOSとLinuxで動作が変わるケースがあることを明示する。

### B-7: AI反論の具体化
rm -rfを使った極端な例→awkを使った集計ズレの例に変更する。「AIが生成したawkコマンドで集計結果がずれたが、パイプの各段階を理解していたので原因を特定できた」という現実的なシナリオのほうが、読者の共感を得やすく、かつ本書の主張（思考法の重要性）を的確に示す。

## C（改善提案）

### C-1: 第7章シーン分解にログインシェル/非ログイン対話シェルのコラムを追加
第7章のドットファイル解説のシーン分解に、ログインシェルと非ログイン対話シェルの違いを扱うコラム（☕マーク）を追加する。`source ~/.bashrc`が必要な場面と不要な場面の違いなど、実務でよく混乱する内容を取り上げる。

### C-2: 実践ワークへのmacOS/WSL2注意事項の追記
各章の「やってみよう」（実践ワーク）の冒頭に、本書がUbuntu環境を前提としており、macOSおよびWSL2では一部コマンドの挙動が異なる場合がある旨を注記する。特にsed・awk・dateコマンド等BSD/GNU差異が顕著なコマンドを使用する章では個別に補足する。
