## 指摘一覧

### 指摘1: タイトルフォーマットがシリーズ共通ルールに則っていない（全書籍共通）
- **対象:** セクション4（タイトル・サブタイトル候補）
- **優先度:** HIGH
- **問題:** シリーズ共通のタイトルフォーマット「ストーリーで学ぶ〇〇入門」が考慮されていない。現状は5案すべてが独自タイトルのみ
- **あるべき形:**
  - プランA: 「ストーリーで学ぶ〇〇入門」フォーマットに則ったタイトル + サブタイトル
  - プランB, C: フォーマットから外れた独自タイトル案 + サブタイトル
- **スコープ:** 本書だけでなく、thinking-hub作成スキル（`/book-start`）にもルールとして反映すべき

### 指摘2: 価格がシリーズ統一価格を前提としていない（全書籍共通）
- **対象:** セクション10-1（推奨価格帯）
- **優先度:** HIGH
- **問題:** シリーズ統一価格（Kindle 980円、ペーパーバック 2,970円）が明記されていない可能性がある
- **あるべき形:** セクション10-1の推奨価格帯に、Kindle 980円・ペーパーバック 2,970円を固定値として記載
- **スコープ:** `/book-start` スキルにもルールとして反映すべき

### 指摘3: 高橋部長の「上から言われてる」が立場に合わない
- **対象:** セクション11、第1章冒頭シーン
- **優先度:** MEDIUM
- **問題:** 高橋部長が「上から言われてる」と発言する設定だが、部長の上は経営層。「上から言われてる」は中間管理職のニュアンスが強く、部長職の立場と合わない
- **対応案:** 高橋部長自身の判断として指示する形にするか、「経営会議で決まった」など具体的な表現に変更

### 指摘4: 佐藤さん初登場時に軽い紹介が必要
- **対象:** セクション11、第1章の佐藤さんに相談するシーン
- **優先度:** HIGH
- **問題:** 佐藤さんが紹介なしに登場する。シリーズ既読者には馴染みがあるが、本書が初めての読者が多いため、初登場時に軽い紹介（職種・田中さんとの関係性）を本文に盛り込むべき
- **対応案:** 「チームのシニアエンジニアで、田中さんが入社以来なにかと相談してきた先輩」程度の地の文での紹介を挿入

### 指摘5: OSSなのに有料契約が必要な点・セキュリティをコラムで取り上げたい
- **対象:** セクション11（シーン分解）または執筆時のコラム設計
- **優先度:** HIGH
- **問題:** Codex CLIはApache-2.0のOSSだが、実際にはChatGPT Plus等の有料契約がないと使えない。このギャップは読者も疑問に思うはず。また、コードがOpenAIのモデル学習に使われないか等のセキュリティ面の懸念も、企業利用を考える読者には重要な関心事
- **あるべき形:** コラム（☕）で以下を取り上げる:
  - 「OSSなのになぜ有料？」→ CLIツール自体はOSS、APIアクセス（モデル利用）に課金が必要という構造の説明
  - セキュリティ面: 送信したコードが学習に使われるのか？企業利用時の注意点
  - ChatGPT Plus / Pro / API直接利用の違いと使い分け
- **配置候補:** 第1章（セットアップ後）または第2章あたりが自然

### 指摘6: シーン2-1の流れをストーリーとして把握しやすくする
- **対象:** セクション11、第2章シーン2-1
- **優先度:** MEDIUM
- **問題:** シーン2-1の記載が箇条書き的で、本文執筆時にストーリーの流れ（起承転結・場面転換・感情の動き）が把握しにくい
- **あるべき形:** thinking-hubのシーン分解の段階で、ストーリーの流れが自然に読み取れるよう、場面の展開順・田中さんの心理変化・会話の流れを意識した記載にする

### 指摘7: full-auto/dangerouslyフラグの禁止はチームルールだけでなくAGENTS.mdでも対処
- **対象:** セクション11、第3章のfull-auto事故シーン
- **優先度:** MEDIUM
- **問題:** 現状「チームルールとして原則禁止」という記載だが、AGENTS.mdに禁止ルールを書くことでCodex側にも制約を認識させられる。ただし設定レベルでの強制禁止機能は現状ないため、CLIフラグを人間が付ければ突破可能
- **あるべき形:** 「チームルール」+「AGENTS.mdにルールとして明記」の両面で対処する流れにする。AGENTS.mdはClaude CodeにおけるCLAUDE.mdと同様の位置づけであることを読者に伝え、「人間側の運用ルール」と「AI側への指示」の二重防御として描く
- **補足:** AGENTS.mdが登場するのは第3章なので、第2章の事故発生時点では「チームルールとして禁止」にとどめ、第3章でAGENTS.mdを導入する際に「第2章の事故を防ぐルールをAGENTS.mdにも追記する」という流れにする

### 指摘8: 第2章以降、マニアックな内容を初心者にも分かりやすく（全章共通）
- **対象:** セクション11全体、特に第2章以降
- **優先度:** HIGH
- **問題:** シーン分解にはCodex CLI固有の専門的な概念・操作が多く含まれるが、対象読者には「ChatGPTは使ってるけどCLIツールは未体験」層がいる。本文執筆時にthinking-hubの記載をそのまま書くとマニアックになりすぎる
- **あるべき形:** 本文執筆時に、各概念・操作を初めて触れる読者でも理解できる平易な説明に落とし込む。田中さんや鈴木くんが「分からない→やってみる→理解する」の流れで自然に学ぶ形にし、技術解説ボックス（📘）で補足する。これは全章に適用する共通方針

### 指摘9: ChatGPTによる技術的正確性レビュー（19項目）

ChatGPT自体にthinking-hubをレビューさせた結果。公式ドキュメントとの照合に基づく技術的正確性の指摘。

#### 要修正（5件） — 書籍として誤情報扱いされやすい

**9-1: `--full-auto`の説明が不正確**
- **対象:** 第2章
- **優先度:** CRITICAL
- **問題:** 本文では`--full-auto = workspace-write + on-request のエイリアス`と書かれているが、公式CLIリファレンスでは「現在のワークスペースと`/tmp`に対する書き込みを承認なしで許可する」もの。`on-request`相当ではなく無人実行寄り
- **修正案:** 「`--full-auto`はunattended local work向けで、ワークスペース内の書き込みを承認なしで進めやすくする」
- **出典:** https://developers.openai.com/codex/cli/reference/

**9-2: AGENTS.mdの由来説明が裏取り不足**
- **対象:** 第3章
- **優先度:** CRITICAL
- **問題:** 「Linux Foundation傘下のAgentic AI Foundationが管理」という説明は、OpenAI公式ドキュメントでは確認できない。事実誤認のリスクが高い
- **修正案:** 「Codexは AGENTS.md を instructions file として読み込める。グローバル、リポジトリ単位、ディレクトリ単位で重ねられる」に留める
- **出典:** https://developers.openai.com/codex/guides/agents-md/

**9-3: Plan / Pair / Executeを公式3モードのように記載**
- **対象:** 第4章
- **優先度:** HIGH
- **問題:** 「Plan / Pair / Execute の3モードが公式機能として並列にある」と読める書き方は危うい。公式に明示的に確認できるのはPlan modeと`exec`（非対話実行）。Pairは概念としては通じるが公式用語ではない
- **修正案:** 「対話型の通常セッションを便宜上 Pair と呼ぶ」くらいに留める
- **出典:** https://developers.openai.com/codex/cli/features/

**9-4: `codex cloud exec`に`--env`が必要**
- **対象:** 第6章
- **優先度:** CRITICAL
- **問題:** 本文の例は`codex cloud exec "..."`だけで投げているが、公式リファレンスでは`--env ENV_ID`がrequired
- **修正案:** `codex cloud exec --env <ENV_ID> "..."`に修正
- **出典:** https://developers.openai.com/codex/cli/reference/

**9-5: `codex cloud apply`は誤り、正しくは`codex apply`**
- **対象:** 第6章
- **優先度:** CRITICAL
- **問題:** diff適用コマンドは`codex cloud apply`ではなく`codex apply`
- **修正案:** `codex apply`に修正
- **出典:** https://developers.openai.com/codex/cli/reference/
