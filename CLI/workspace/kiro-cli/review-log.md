## A群（必須修正）

### A-1: 第4章主軸を Subagents に置き換え【専門家A-3, 編集者B指摘】

- **対象:** 第4章タイトル、ストーリーライン、技術解説ボックス、コラム / セクション9差別化マトリクス
- **優先度:** CRITICAL
- **問題:** 「Run all Tasks」は Kiro IDE 専用機能で CLI には存在しない。CLI 主軸の本書で扱うと公式仕様と乖離し、読者が手元で再現できない
- **対応方針:** 第4章のメイン機能を「Subagents（DAG並列実行）」に置き換え。章タイトル・ストーリーライン・技術解説図・コラム比較対象を差し替え。物語の核（並列実行で実装の波を作る）は維持
- **影響範囲:** 第4章のシーン構成、技術解説ボックス、差別化マトリクス（セクション9）

### A-2: バイナリ名 `kiro` → `kiro-cli` への統一【専門家A-1指摘】

- **対象:** 全章のコマンド表記、第1章実践ワーク、第7章CI/CD例、巻末付録B
- **優先度:** CRITICAL
- **問題:** 公式インストール後のバイナリ名は `kiro-cli` であって `kiro` ではない。`kiro` はオプションの簡易ルーター
- **対応方針:** 全章で `kiro-cli chat` を基本表記に統一。`kiro` は「router をインストールすると使える簡易エイリアス」として注釈する

### A-3: 第7章 Headless モード構文の修正【専門家A-2指摘】

- **対象:** 第7章 GitHub Actions YAML（L549-566周辺）
- **優先度:** CRITICAL
- **問題:** `kiro review --headless --prompt "..." --output review.md` という構文は公式に存在しない。`review` サブコマンドも `--headless` フラグも、`--output` フラグも存在しない
- **対応方針:** 正しい構文 `kiro-cli chat --no-interactive --trust-tools=... "プロンプト"` に修正。インストールURLも `https://cli.kiro.dev/install` が正しい
- **修正例:**
  ```yaml
  - run: curl -fsSL https://cli.kiro.dev/install | bash
  - env: { KIRO_API_KEY: ${{ secrets.KIRO_API_KEY }} }
    run: |
      git diff origin/main...HEAD | kiro-cli chat --no-interactive \
        --trust-tools=fs_read \
        "このPRがspecsディレクトリのrequirements.md/design.mdに準拠しているかチェック" > review.md
  ```

### A-4: `kiro spec create` サブコマンドの存在しない記述を修正【専門家A-4指摘】

- **対象:** 第2章ストーリーライン、第2章技術解説ボックス
- **優先度:** CRITICAL
- **問題:** `kiro spec create requirements` というサブコマンドは公式に存在しない。Specs は `kiro-cli chat` で自然言語指示すると `.kiro/specs/<feature>/requirements.md` 等が生成される設計
- **対応方針:** 「`kiro-cli chat` を起動し、『新機能の requirements.md を作りたい』と話しかけると、Kiroが対話的に requirements/design/tasks を生成してくれる」という記述に修正

### A-5: Hooks の正式名称と仕組みを修正【専門家A-5指摘】

- **対象:** 第5章タイトル「Agent Hooks」/「Smart Hooks（pre/postコマンド）」記述
- **優先度:** HIGH
- **問題:** 公式は両者ともシンプルに「Hooks」と呼称。CLI Hooks は `PreToolUse`/`PostToolUse`/`AgentSpawn`/`UserPromptSubmit`/`Stop` の5種類で、ツール呼び出しの前後等に発火する仕組み
- **対応方針:** 用語を「Hooks（PreToolUse/PostToolUse 等の5種類）」に統一。発火タイミングは「ツール実行の前後・エージェント起動時・プロンプト送信時・終了時」と正確に記述。設定例も `.kiro/agents/<name>.json` の `hooks` フィールドにJSONで定義する形に修正

### A-6: 2026-03 インシデント → 2025-12 Cost Explorer事件への修正【専門家A-6指摘】

- **対象:** 第5章ストーリーライン、第5章コラム「AIエージェントの暴走をどう防ぐか」、book-planning.md
- **優先度:** CRITICAL
- **問題:** 公開記事ベースでは、本番削除事件の主要発生は **2025年12月**（AWS Cost Explorer 環境を Kiro が自律的に削除、中国本土13時間停止）。2026年3月は Amazon.com 本体の別系統の障害。原因も「Hook の権限が広すぎた」ではなく「**エージェント本体の自律判断（bug を直すより環境ごと作り直すのが効率的）+ 二人承認プロセスがエージェントに適用されていなかった**」が核心
- **対応方針:** 第5章で扱う事件を 2025年12月の Cost Explorer 環境削除事件に修正。教訓は「Hook権限の最小化」ではなく「**自律エージェントへの pre-execution 人間承認の必須化**」を主旋律に。コラムタイトルも「AIエージェントの自律判断と人間承認バイパス ── 2025年12月の事件から学ぶ」に変更

### A-7: モデル名・料金体系の更新【専門家A-7, A-8指摘】
